# plaintop — общие части текстового монитора и его хост со сквозными кликами

[English](README.md) · Русский

Текстовый монитор работает в двух хостах. Отрисовка и данные лежат здесь, поэтому оба
рисуют одно и то же одним кодом.

| Путь | Что это |
|---|---|
| `shared/MonitorData.qml` | подписки, разовые чтения, редкие команды и сборка строк по описанию |
| `shared/MonitorView.qml` | рисует эти строки; палитра живёт здесь, а каждый кусок строки несёт роль, а не цвет |
| `window/window.qml` | хост со сквозными кликами: окно с `Qt.WindowTransparentForInput` |
| `window/setup.py` | раскладывает его, пишет правило KWin и автозапуск, переносит настройки из плазмоида |
| `../plasmoid/package/` | хост-плазмоид, со штатным диалогом настроек Plasma |

`install.sh` копирует два общих файла в тот хост, который ставит. Две правленные копии
одного QML — верный способ тихо разъехаться.

## Зачем два хоста

Плазмоид на рабочем столе не отдаёт левую кнопку мыши — четыре способа проверены, см.
`../docs/GOTCHAS.ru.md`. Обычное окно с `Qt.WindowTransparentForInput` отдаёт, поэтому
монитор может лежать поверх стола, не отбирая клики у ярлыков под ним.

Чем за это платит оконный хост: нет штатного диалога настроек, нет управления сессией и
нет самостоятельного размещения — под Wayland окно не может задать себе место, поэтому
место, размер, «держать снизу» и «мимо панели задач» задаются правилом KWin по заголовку.

## Установка

```bash
./install.sh --plaintop-window     # разложить, записать правило KWin и автозапуск, запустить
./install.sh --plaintop-export     # перенести текущие настройки плазмоида в файл окна
./install.sh --plasmoid            # хост-плазмоид (на стол не сажается, если есть окно)
./install.sh --status              # оба хоста
```

На столе должен быть один хост: они рисуют одно и то же.

## Настройки

`~/.config/plaintop/monitor.json` — внешний вид и описание блоков в одном файле: шрифт,
кегль, отступы, размер виджета, интервал обновления, четыре цвета палитры и `blocks`.
Окно перечитывает файл каждые две секунды, поэтому правка видна без перезапуска.

**Редактором пока остаётся диалог плазмоида.** `--plaintop-export` читает то, что этот
диалог сохранил, и пишет сюда — так у обоих хостов один редактор, пока у оконного не
появится свой. У визуализатора такой уже есть: `../spectrum/window/settings.qml`.

Чтобы сдвинуть монитор, поправьте правило KWin (Параметры системы → Правила окон) или
запустите `--plaintop-window` с переменными `PLAINTOP_X` / `PLAINTOP_Y`. Зазор от края
экрана рисуется внутри виджета (`padLeft`, `padTop`) — поэтому правило держит окно в `0,0`.

## Что предстоит

- **Редактор для оконного хоста**, как у визуализатора, чтобы плазмоид не требовался
  ради диалога настроек.
- **Одно имя на один виджет.** Хост-плазмоид исторически лежит в `../plasmoid/`, а его
  общие части — здесь; `monitor/package`, `monitor/shared`, `monitor/window` читались бы
  лучше, и переименование механическое.
