# editor — редактор виджета

Приложение на PySide6 (уже установлен в системе, выглядит нативно в KDE).

Что должен уметь:
- включать и выключать блоки, менять их порядок перетаскиванием;
- править внешний вид: цвета, шрифты и кегли, ширину, положение на экране, длину полосок;
- настраивать параметры блоков: сколько процессов в топе, какие диски показывать,
  какой сетевой интерфейс, интервалы обновления;
- **добавлять свои блоки с нуля** — произвольной командой или датчиком, без знания
  синтаксиса conky;
- применять изменения с перезапуском виджета и откатывать к предыдущему состоянию.

Работает поверх `schema/widget.json`, сам синтаксис conky не трогает — его знает только
генератор.
