# Проверка на ПК: календарь 0.2 (заметки) и монитор 0.5 (активные строки)

Одноразовый список для сессии на s1dPC. Оба куска написаны в облаке без Qt, статика
пройдена, живого Plasma не было. Порядок — от дешёвого к дорогому; что упало — чинить
по месту и записывать в журнал, файл после прохода удалить (как `VERIFY-2026-10-04.md`).
Правила — `CLAUDE.md`, грабли — `docs/GOTCHAS.md`, метод — `docs/WORKFLOW.md`.

## 2. Монитор 0.5 на столе

`./install.sh --plasmoid`, журнал фильтровать по `org.s1dd1`. Настройка «Мышь» сначала
выключена (виджет берёт клики как любой).

- Наведение на строку с действием → рамка 1 px цветом значений; на разделитель, пустую
  строку, текст без `click` — нет.
- Левый клик: CPU → `plasma-systemmonitor`; диск → папка в файловом менеджере; юнит
  (добавить блок units с `nginx.service` или любым) → терминал со `systemctl status`;
  заголовок → диалог настроек виджета; звук → тишина переключилась (строка обновится
  через ≤5 с); строка процесса → вопрос «имя pid: завершить имя?» с `> нет` по умолчанию,
  Esc закрывает, ничего не убито.
- Правый клик на любой активной строке → меню в рамке `┌─ заголовок ───┐`, пункты с `>`,
  стрелки/Enter/Esc работают (фокус в диалоге под Wayland — проверить именно это),
  наведение переносит маркер, клик по пункту выполняет. Клик мимо меню закрывает его
  (`hideOnWindowDeactivate`). Положение: сейчас `location: TopEdge` — меню под строкой,
  по центру; если выходит криво, поменять `location` в `ActionMenu.qml` (свойство) или
  якорь в `main.qml` (`anchor` на прямоугольнике строки).
- Терминал: по умолчанию `konsole -e sh -c '…'` через `setsid -f`; у «удерживаемых»
  (`systemctl --failed`, `ip -c addr`, обновления) окно ждёт Enter. Проверить, что
  перезапуск `plasmashell --replace` терминал не убивает.
- Ошибка команды: `kill -TERM` чужого процесса (например, PID 1 через свою команду
  `click: kill -TERM 1` на любом блоке) → уведомление в той же рамке с первой строкой
  stderr и пунктом `ok`.
- Страница «Блоки»: «Активный» снят → строки блока без рамки и кликов; «Клик»:
  `notify-send {name} {value}` на блоке cpu → уведомление с числами. JSON-вид показывает
  поля `active`/`click`.
- Страница «Общее»: переключатель «Активные строки» выключает всё; «Терминал», «Редактор»,
  «Рамка меню» (8 символов), «Бумага меню», непрозрачность — применяются без перезапуска.
- **Сквозные клики + активные строки** (главное): включить «Мышь». Клик по обоям между
  строками и справа от текста — доходит до стола (ярлык/меню стола); клик по CPU —
  действие; правый клик по пустому месту виджета — меню **стола**, по активной строке —
  наше; наведение на пассивные строки курсор не меняет. В журнале не должно быть
  «Object set as mask does not have an invokable contains method» — если есть, сработал
  откат на прямоугольник (`plaintop: the function mask was refused`): тогда п. 1,
  тест 18, и решение 14 переписывается.
- Режим правки стола: виджет двигается и меняет размер целиком, как раньше; выход из
  режима — маска вернулась.
- `./install.sh --palette tachikoma-rooftops` — ключ `colorPaper` у монитора пишется,
  старые палитры без него грузятся; `--palette-save` сохраняет его.
- Нагрузка: `top` по plasmashell при наведении мышью по виджету — функция маски зовётся
  на каждое движение, должно быть незаметно.

## 3. Календарь 0.2 на столе

`./install.sh --calendar`. Заметки включены по умолчанию, аккаунт — локальный.

- Клик по дню → стикер **у ячейки** (`PlasmaCore.Dialog`, `visualParent` — якорь на
  ячейке, `location: Floating`): где именно встаёт — записать; фокус сразу в редакторе;
  Esc и клик мимо закрывают; напечатать текст, закрыть → день покрасился цветом заметок,
  строка в «ближайших» (если дата в окне), файл `~/.local/share/plaincalendar/notes/*.ics`
  появился; пустой текст → удаление. Рамка 1 px при наведении на ячейку, тусклее — у
  открытого стикера. Анимация «разворот» не меняет размер окна; «fade» и «нет».
  Боковые рамки редактора совпадают с числом строк при переносе длинного текста.
- Сквозные клики: заметки включены — маска только по сетке дней (обои вокруг кликаются,
  правый клик вне сетки — меню стола); выключены — весь виджет сквозной, как в 0.1.
- Аккаунты: «Аккаунты» → пресет Яндекс, логин, пароль приложения, «Проверить» →
  перечисляет календари; выбрать, «Сохранить»; через синхронизацию записи с сервера в
  стикере и в «ближайших»; на «Заметках» «куда писать» = Яндекс → заметка появляется в
  веб-календаре. Пароль в `~/.config/plaincalendar/accounts.json` (600), в командной
  строке плазмоида его быть не должно (`ps`). iCloud — principal на другом хосте,
  редиректы следуем сами. Google — `python3 …/notes.py google-auth ID` в терминале со
  своими client id/secret. ICS — любой публичный `.ics`.
- `python3 calendar/package/contents/code/notes.py sync --every 1 --upcoming 3` руками —
  документ JSON, аккаунты с `ok`.
