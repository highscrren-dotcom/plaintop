## 2026-09-20 (вторая сессия) — плазмоид догнал conky, слой описания, публикация

**Сделано.** Минимальный плазмоид дорос до полного набора блоков conky-реализации. Данные
берутся у ksystemstats по подписке (решение 2 в `DECISIONS.md`), топ процессов — через
`ProcessDataModel`, файловые системы и службы — редкими запусками команд. Блоки и их
порядок переехали в `schema/widget.json` со словарём типов в `schema/blocks.json`;
`plasmoid/generate.py` проверяет описание и кладёт его в пакет. В настройках появилась
страница «Блоки», включая добавление блоков типов `command` и `sensor`. Репозиторий
подготовлен к публикации: документы парами EN/RU, `LICENSE`, `CONTRIBUTING`, скриншот,
зашитые пути домой убраны.

**Проверено исполнением.** Установка пакета и появление виджета; смена `updateInterval`
1000 → 4000 меняет частоту тиков живого виджета; под нагрузкой строка CPU идёт 0 % → 34 %,
температура 19 → 27 °C; выключение блоков через хранилище перестраивает виджет; «своя
команда» показала вывод `uptime -p`. Цена по процессору: plasmashell 2,8 % одного ядра
без виджета, 4,4 % с ним. Диалог настроек открыл пользователь — в конфиге появилась его
правка (дата переставлена выше часов, кегль 9, отступы 12), то есть страница «Блоки»
работает.

**Что не получилось с первого раза** — здесь самое ценное:

- **Место апплета.** Пять способов подряд мимо: координаты в `addWidget` игнорируются,
  присваивание `geometry` молча не работает, `Qt.rect` в скриптинге не существует, запись
  `ItemGeometries` при живой оболочке затирается, при остановленной — всё равно
  сбрасывается в 0,0. Правильный ответ оказался в другой плоскости: зазор рисуется внутри
  виджета. Стоило пользователю раздражения и прямого «забей на расположение».
- **`Layout.minimum*` от содержимого.** Подсказка размера, считавшаяся от высоты текста,
  заставляла контейнер пересобирать раскладку каждый раз, когда доезжали диски и службы, —
  и виджет улетал в угол. Постоянный размер из настроек это снял.
- **Почти записал непроверенное.** Проверял кэш QML меткой через `console.log` — метка не
  появилась, и вывод «пересоздание апплета не помогает» был бы ни на чём не основан:
  `console.log` мог просто не доехать до журнала. Перепроверил через `console.warn` —
  вывод подтвердился, но правильным он стал только после второй проверки.
- **Гонка при записи конфига.** `systemctl stop` возвращается раньше, чем plasmashell
  допишет `appletsrc`, и правка затиралась. Ожидание фактического исчезновения процесса
  помогло — но сама затея с закреплением места всё равно оказалась тупиковой.
- **Залимитировал перезапуски.** Частые `systemctl restart plasma-plasmashell` упёрлись в
  systemd: «start request repeated too quickly», рабочий стол остался без панели.
  Понадобился `reset-failed`. Между перезапусками нужна пауза.
- **Дубли id в подписке.** `SensorDataModel` схлопывает одинаковые сенсоры: 4 id → 3
  столбца, чтение по индексу уехало в `undefined`, и свой датчик показывал ноль.
- **Свой heredoc.** Внутренний ограничитель совпал с внешним и оборвал мою же команду на
  середине; install.sh уцелел случайно. Мелочь, но в следующий раз ограничители разные.

**Где остановились.** Плазмоид функционально догнал conky, репозиторий готов к публикации.
Дальше — цвета в настройки, температуры по пакетам CPU, R/W диска, генератор для conky.
См. `STATE.md`.

**Позже в той же сессии — публикация.** Репозиторий сделан публикуемым: документы парами
EN/RU, `LICENSE` (GPL-2.0-or-later), `CONTRIBUTING` с призывом к форкам, скриншот,
зашитые `/home/<кто-то>` убраны (`@HOME@` подставляется при раскладке). Комментарии в коде
переведены на английский тремя агентами; строки, которые видит пользователь, оставлены
русскими — это интерфейс, для него нужна настоящая локализация. `CLAUDE.md` выведен из
репозитория (`git rm --cached` + `.gitignore`); ⚠️ в уже отправленной истории он остался,
убрать оттуда можно только перезаписью истории — не делалось.

**Ещё один промах, тот же по природе.** Добавляя в `install.sh` ключ «разложить без
запуска», я сделал замену по строке `status() {` — и она попала внутрь `plasmoid_status`,
раскрошив файл. Это ровно та же ошибка, что и в первый раз за сессию: замена по
неуникальной строке. Перевод пришлось откатить и попросить агента повторить, а свою правку
я переделал с проверкой единственности якоря перед заменой. Вывод простой: замена в коде
без проверки `count == 1` — не правка, а лотерея.

Попутно нашлось: раскладка файлов conky затирала `Hidden=true` в автозапуске, то есть
«разложить» молча включало погашенную реализацию. Теперь раскладка состояние сохраняет,
а включает его только полная установка — она и означает «разложить и запустить».

**Решения сессии.** Данные — из сенсоров (`DECISIONS.md`, решение 2). Размер виджета —
настройка с постоянной подсказкой разметки. Место апплета — за пользователем. Язык
репозитория: документы парами EN/RU, рабочий журнал по-русски. Лицензия —
GPL-2.0-or-later, как и заявлено в `metadata.json`.

## 2026-09-20 — заведение проекта и выбор движка

**Сделано.** Виджет вынесен из `~/.config/conky` в отдельный репозиторий. Перенесён код,
написан разбор граблей, заведён `install.sh` с проверками состояния. Выбран движок целевой
реализации — плазмоид Plasma 6; решение с обоснованием записано в `DECISIONS.md`.
Репозиторий отправлен на GitHub.

**Проверено исполнением.** `./install.sh --status`: один процесс conky, окно
`class=conky-plainext`, `input=0` — клики проходят. Все разложенные файлы совпадают
с репозиторием. Виджет пережил три перезагрузки.

**Что не получилось с первого раза** — здесь самое ценное:

- **Трижды подряд чинил не ту половину проблемы.** Виджет после перезагрузки оказывался
  чужим либо ловил клики, и каждый раз находился НОВЫЙ виновник: сессия ksmserver, потом
  KWin через пакетный `conky.desktop`, потом KWin по сохранённой команде. Я закрывал
  найденный путь и считал задачу решённой. Помогло только когда перестал перебирать
  запускающих и сделал операцию идемпотентной. Стоило пользователю двух лишних перезагрузок.
- **Дважды записал в документ непроверенное.** «Conky под Wayland не работает» и
  «`own_window_type='desktop'` под KWin не работает» — оба утверждения сделаны по памяти
  и оба оказались неверны. Первое едва не увело от правильного решения вообще.
- **Ложная проверка click-through.** Проверял через `xdotool mousemove` и поставил «✓».
  Курсор при этом не сдвинулся — под Wayland синтетические движения блокируются, и тест
  показал окно под реальным положением курсора. Вывод был ни на чём не основан.
  Настоящая проверка — чтение input-области из X.
- **Чистка конфига фильтром по слову** снесла `excludeApps=conky` — защиту, поставленную
  строкой выше. Заметил только по содержимому снапшота.
- **`set -o pipefail` + `grep -q`** в собственном `install.sh`: проверка шрифта говорила
  «не найден» при шестнадцати совпадениях.

Все пять записаны в `GOTCHAS.md` и `CLAUDE.md` как запреты.

**Где остановились.** `plasmoid/` пока только с описанием замысла. Следующий шаг —
минимальный работающий пакет, чтобы замкнуть контур «ставится → появляется → настройка
доезжает». См. `STATE.md`.

**Решения сессии.** Движок — плазмоид (`DECISIONS.md`, решение 1). Отдельного редактора
на PySide6 не будет: его роль берёт штатный диалог настроек плазмоида. Владение файлами
`~/.config/conky/*` передано этому репозиторию, из `setup_machine` снапшот убран.
