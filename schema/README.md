# schema — описание виджета

Здесь будет `widget.json` — декларативный список блоков. **От движка не зависит:**
описывает, *что показывать*, а не *как это записать*. Генератор превращает описание
в то, что понимает конкретный движок — QML для плазмоида, `.conf` для conky.

Задуманная форма записи блока:

```json
{
  "id": "cpu",
  "type": "cpu_load",
  "enabled": true,
  "title": "CPU",
  "params": { "show_bar": true, "top_processes": 5, "per_socket": true }
}
```

Рядом ляжет словарь доступных типов блоков: какие есть, какие параметры принимают,
что выводят. Диалог настроек строится именно по этому словарю, а не по захардкоженному списку —
иначе добавление нового типа блока потребует правки интерфейса.
