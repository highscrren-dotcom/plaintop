# schema — описание виджета

Здесь будет `widget.json` — декларативный список блоков, из которого генератор собирает
рабочие `widget/plainext.conf` и `plainext.lua`.

Задуманная форма записи блока:

```json
{
  "id": "cpu",
  "type": "cpu_load",
  "enabled": true,
  "title": "CPU",
  "params": { "show_bar": true, "top_processes": 5, "per_socket": true }
}
```

Рядом ляжет словарь доступных типов блоков: какие есть, какие параметры принимают,
что выводят. Редактор строит интерфейс именно по этому словарю, а не по захардкоженному
списку — иначе добавление нового типа блока потребует правки редактора.
