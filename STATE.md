## Где мы

**Работают два виджета, оба свои, у каждого два хоста. На столе сейчас окна** (сквозь
них проходят обе кнопки мыши); плазмоиды установлены, но на стол не посажены.

- **Текстовый монитор** — `plasmoid/` (хост-плазмоид) и `plaintop/` (общие `shared/` плюс
  `window/` — хост-окно и редактор). Весь набор блоков conky-реализации: заголовок, часы,
  дата, система, CPU общий и по узлам NUMA, модель процессора с температурами и оборотами,
  топ по CPU, ОЗУ с топом по памяти, GPU с VRAM, диски с температурой NVMe, аптайм, сеть,
  docker/ollama/обновления, паспорт железа. Набор и порядок блоков — данные
  (`schema/widget.json`).
  **Редактор** — `./install.sh --plaintop-settings`: настройки слева, раскладка справа
  настоящим движком. Привязанные к машине параметры выбираются из того, что машина отдаёт.
- **Датчики находятся сами** (решение 6): `SensorRegistry` перечисляет дерево, сохранённый
  идентификатор — лишь предпочтение, пустой — «найти самому». Проверено перезагрузкой:
  после неё всё нашлось без правок. В репозитории нет ни идентификаторов железа s1dPC, ни
  личных путей.
- **`spectrum/`** — визуализатор звука: кольцо, дуга или линия из штрихов. Источник —
  `cava` через службу-реле по локальному HTTP; реле же единственный писатель настроек
  обоих виджетов. В тишине кольцо растворяется, опрос падает до 4 раз в секунду.
  Реле переживает поздний старт PipeWire при загрузке (перезапуски с отступом до 10 с).
- **`conky/`** — погашена (`./install.sh --conky-on` возвращает), живёт до замены.

**Репозиторий публичный**: документы парами EN/RU, `LICENSE` (GPL-2.0-or-later),
`CONTRIBUTING` с призывом к форкам, скриншот.

| | Процессор |
|---|---|
| Окно монитора | 8,4 % ядра (сбор ~4,6 %, отрисовка ~4 %) |

## Следующий шаг

- **Отрисовка окна монитора** — ~4 % ядра за 40 строк текста раз в секунду многовато;
  разобрать, что именно перерисовывается (все `Text` или только изменившиеся).
- **Выбор сети по умолчанию.** `netIface` берёт первый интерфейс из дерева; здесь это
  `enp5s0`, но рядом `docker0` и `singbox_tun` — на другой машине автопоиск может взять
  не тот. Нужен признак «настоящий» (есть трафик, не виртуальный).
- **Одно имя на один виджет:** `plasmoid/` + `plaintop/` → `monitor/{package,shared,window}`.
  Переименование механическое, задевает `install.sh`, оба `setup.py` и ссылки в документах.

Выбрать из накопившегося:

- **спектр: пик-холд**, выбор устройства прямо в редакторе (сейчас
  `~/.config/plainspectrum/relay.env`), пауза под полноэкранным окном, диапазон частот;
- **температуры по пакетам CPU** — сейчас максимум по ядрам узла (23/20 °C против 27/26 у
  conky); за пакетами идти в `sensors -u`;
- **чтение и запись диска** в строке «/» — у conky там было `R:` и `W:`;
- **заголовок по умолчанию** `s1dd1\Dashboard` — имя автора; собирать из имени
  пользователя той машины, где стоит виджет;
- **генератор для conky** — слой описания задумывался общим на оба движка;
- **проверка на второй машине** — всё сделано для этого, но проверено только здесь.

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (`docs/DECISIONS.md`, решение 1).
- Данные — сенсоры ksystemstats, не `/proc` своими руками (решение 2).
- Визуализатор свой, а не готовый (решение 4, оно отменило решение 3).
- Рисуем процессором, видеокарту не нагружаем; путь через шейдер не берём.
- **Сквозные клики — оконным хостом** (решение 5): плазмоид левую кнопку не отдаёт,
  четыре способа проверены. Цена: свой редактор, правило KWin на место, свой автозапуск.
- **Датчики находятся сами** (решение 6): предпочтение плюс шаблон, отдельные объекты
  `Sensors.Sensor` вместо доверия общей модели, `pick` в словаре для редактора.
- Окна ищутся по таблице процессов, не по PID-файлу и никогда не `pkill -f`.
- Размер виджета — настройка; подсказка `Layout.*` должна быть постоянной.

## Открытые вопросы

- **Судьба conky-реализации** после замены: удалять или оставить запасной.
- **Локализация.** Интерфейс и вывод `install.sh` по-русски, репозиторий англоязычный.
  Правильный путь — каталоги переводов, решения пока нет.
- **Точки монтирования никто не угадает** — для них нет шаблона; редактор предлагает
  список, выбор за пользователем.
