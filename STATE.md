## Что уже решено, не пересматривать без причины

- Движок — плазмоид (1). Данные — ksystemstats (2). Визуализатор свой (4). Датчики находятся
  сами (6). Переводы — ki18n (7). Сквозные клики — самим плазмоидом (8), окна погашены (9).
- Погода — прямые запросы из QML (10), несколько источников за одной абстракцией, Яндекс нет (13).
  Плеер: маска по кнопкам (11), в спектре как опция и отдельным виджетом (12).
- Каналы спектра — свёртка в реле по запросу виджета, cava остаётся стерео.
- Активные строки монитора (14): включены по умолчанию; левый клик — одно действие,
  остальное в меню; разрушительное — после вопроса; `active`/`click` — поля блока, не
  параметры словаря; маска при сквозных кликах — функция, откат — прямоугольник.
- Заметки календаря: один протокол на троих — CalDAV (Google отличается только OAuth);
  хелпер на Python в пакете виджета, не служба; одна запись на день; стикер — диалог без
  фона с рамкой символами; аккаунты — динамический список, локальный vdir есть всегда;
  секреты не ходят в командной строке.
- Чужие ветки вливаются слиянием, локальные коммиты не переписываются.
- Никогда не `pkill -f`. Синтетическая мышь под Wayland — только uinput. Звук для рендеров и
  проверок — только через null-sink, не колонки.

## Окружение

s1dPC: CachyOS, Plasma 6.7.5, KDE Frameworks 6.30, KWin Wayland, Qt 6.11.2. Два экрана:
DP-1 3440×1440 (основной, контейнер 66) и HDMI-A-1 1080×1920 вертикальный (контейнер 111).
`cava` 1.0.0, `lm_sensors`, gettext, `ttf-jetbrains-mono-nerd`, `python-evdev`, `vlc`, `mpv`.
`kdeplasma-addons` стоит, но QML погоды из него не импортировать. Пользователь в `wheel`.
⚠️ Qt-программы пишут в journald, когда stderr не терминал: `QT_FORCE_STDERR_LOGGING=1`.
⚠️ Журнал plasmashell забит ошибками стороннего `luisbocanegra.panel.colorizer` — фильтровать
по `org.s1dd1`. У WirePlumber нет источника по умолчанию — блок «Звук» без строки `MIC`.
Скриншот без диалогов: `spectacle -b -n -f -o файл`; стол из-под окон — «Show Desktop» через
`qdbus6 org.kde.kglobalaccel /component/kwin org.kde.kglobalaccel.Component.invokeShortcut
"Show Desktop"` на секунду-две; при блокировке экрана кадр покажет блокировщик.
Весь трафик через `singbox_tun`; api.open-meteo.com с этой машины не проходит — погода на Met.no.
Облачный контейнер: Qt и `xgettext` отсутствуют — QML и каталоги там проверяются только статикой
(проверщик скобок и каталогов — одноразовые скрипты сессии, в репозиторий не входят).

⚠️ Метод работы — `docs/WORKFLOW.md`, грабли — `docs/GOTCHAS.md`
(читать до правки конфигов и QML).
