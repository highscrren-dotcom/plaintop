## Задача — плеер в центре спектра, мышь только у кнопок (выбрано пользователем 23.09)

**Публикация 0.3 на паузе** по слову пользователя; пакеты лежат в `dist/`, тексты в `STORE.md`.

**Состав.** (1) Стенд: подпрямоугольная `containmentMask` на обёртке апплета — клик внутри
прямоугольника доходит до `MouseArea` виджета, снаружи уходит на стол; правая кнопка так же;
в режиме правки маска снимается. Расширить `tests/passthrough.qml`. (2) `PlayerView.qml`
становится общим (`player/shared/`, копируется в оба пакета при установке, как `monitor/shared`).
(3) Спектр получает опцию «плеер в центре кольца» со своей страницей настроек; без игрока в
центре пусто. (4) В обоих хостах при включённой «Мыши» мышь ловит только строка кнопок `<<  >  >>`,
остальное сквозное. Отдельный виджет `plainplayer` остаётся.

## Где мы

**Четыре виджета, один хост — плазмоид.** Стол: монитор (0,0), спектр, плеер (1824,720),
погода (1824,1264). `--status` весь зелёный, журнал без ошибок от пакетов.

- **Монитор 0.3**: блоки `pressure` (PSI, ksystemstats `pressure/*`, параметр `full`), `battery`
  (`power/<id>/*`, только при ёмкости > 0 — иначе мышь считается батареей; **на железе не
  проверен**, машина без батареи), `health` (`health.sh`: упавшие юниты, ошибки с загрузки,
  последние строки journald; 34–43 мс; гейт по включённому блоку). Соседние разделители
  схлопываются. Ширина в колонках считается из метрик шрифта (57 при 500 px).
- **Плеер** `player/` — `org.kde.plasma.private.mpris`, мультиплексор «кто играет»; «Мышь» по
  умолчанию выключена (решение 11): сквозь клики кнопки не нажать. Запасной путь при поломке
  модуля — `org.kde.plasma.workspace.dbus` (только комментарий в коде).
- **Погода** `weather/` — Open-Meteo прямо из QML, без реле (решение 10); 15 мин, сторож 10 с,
  бэкофф, кэш в конфиге; место — поиск города / «lat, lon» / угадано по часовому поясу; единицы
  по локали; атрибуция включена (лицензия CC BY 4.0, некоммерческое использование).
- **Переводы**: четыре домена × 9 языков, машинные, 36 каталогов проходят `msgfmt --check`.
- **conky/** и код оконных хостов — лежат, погашены.

⚠️ `/usr/bin/{qml,qmllint,qmltestrunner}` — Qt 5; рабочие — в `/usr/lib/qt6/bin/`.
⚠️ `plasmawindowed` одноэкземплярный: второй стенд молча выходит с кодом 0.

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (1). Данные — ksystemstats (2). Визуализатор свой (4). Датчики находятся
  сами (6). Переводы — ki18n (7). Сквозные клики — самим плазмоидом (8), окна погашены (9).
- Погода — прямые запросы из QML, без реле (10). Плеер кликабелен по умолчанию (11).
- Никогда не `pkill -f`. Синтетическая мышь под Wayland — только uinput. Разделители в
  командах моего инструмента — без `=` (zsh: `=cmd`).

## Окружение

`cava` 1.0.0, `lm_sensors`, gettext, `ttf-jetbrains-mono-nerd`, `python-evdev`, `vlc`, `mpv`.
`kdeplasma-addons` стоит, но QML погоды из него не импортировать. Пользователь в `wheel` —
системный журнал читается через ACL.
⚠️ Qt-программы пишут в journald, когда stderr не терминал: `QT_FORCE_STDERR_LOGGING=1`.
Скриншот без диалогов: `spectacle -b -n -o файл`; стол из-под окон — «Show Desktop» через
`qdbus6 org.kde.kglobalaccel /component/kwin … invokeShortcut` на две секунды.
Весь трафик через `singbox_tun`; api.open-meteo.com отвечает за ~0,5 с.
