## Задача — несколько источников погоды (выбрано пользователем 23.09, «делаем»)

**Состав.** В `plainweather` абстракция «источник»: `{id, name, needsKey, build(lat, lon, days, key)
→ {url, headers}, parse(json) → общая форма {current, daily[]}, attribution}`; коды условий —
WMO (одна таблица слов); единицы всегда метрические от источника, конвертация в виджете; ключ —
поле в настройках только у ключевых; кэш с `sourceId`, смена источника сбрасывает кэш.
Источники: **Open-Meteo** (по умолчанию), **Met.no** (без ключа; `User-Agent` обязателен,
`If-Modified-Since`/`Expires`; min/max из почасовых точек; отвечает из РФ), **WeatherAPI.com**
и **Visual Crossing** (ключ пользователя). Атрибуция по источнику. Геокодер остаётся Open-Meteo
(его хост отвечает). Порядок: абстракция + Met.no → ревью → ключевые → переводы → документы →
набор `plainweather` на столе обновить.

**Публикация 0.3** — по-прежнему за пользователем, папки на столе готовы (см. журнал 23.09).

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (1). Данные — ksystemstats (2). Визуализатор свой (4). Датчики находятся
  сами (6). Переводы — ki18n (7). Сквозные клики — самим плазмоидом (8), окна погашены (9).
- Погода — прямые запросы из QML (10). Плеер: маска по кнопкам (11), в спектре как опция и
  отдельным виджетом (12).
- Никогда не `pkill -f`. Синтетическая мышь под Wayland — только uinput. Звук для рендеров —
  только симуляция через null-sink, не колонки.
