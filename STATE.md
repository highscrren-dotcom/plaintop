## Где мы

**Пять виджетов, один хост — плазмоид.** Версии: plaintop 0.5, plainspectrum 0.4,
plainplayer 0.1, plainweather 0.1, plaincalendar 0.3 — все на столе, `--status` чистый,
`dist/` собран. В магазине (API): plaintop 0.4, plainspectrum 0.4, plaincalendar 0.1
(https://store.kde.org/p/2377077/), plainplayer 0.1, plainweather 0.1.

- **Монитор 0.5 — активные строки** (решение 14, проверено на столе): клики, меню в рамке,
  маска-функция (`--check-passthrough` 20/20), программы из действий — в своём scope systemd.
- **Календарь 0.3** (решение 15 с поправкой 04.10, проверено на столе): стикер — список своих
  заметок дня (клик открывает в редакторе, «+ новая заметка»), под редактором «время: `__:__`»
  (маска, курсор в начало) и «напомнить:» (нет / за N мин / за час, или нет / в 09:00). Каждая
  заметка — свой VEVENT: первая `plaincalendar-ДАТА@хост`, следующие с хвостом
  (`notes.py set/delete --uid`). Лист напоминания (Notification) у ячейки дня; ключ звонка —
  с временем по данным, заявка — на каждый звонок; записи — очередью. Звук звонка — нет /
  пять своих сигналов (`calendar/sounds.py` → `contents/sounds/*.wav`) / свой файл, кнопка
  «Прослушать»; по умолчанию выключен. «Ближайшие»: сначала неотвеченные прошедшие звонки
  (`missed`, «!» акцентом, клик → лист), затем будущее; запись со временем уходит после
  конца; документ — раз в минуту (аккаунты — раз в `syncMinutes`). **Яндекс настроен**
  (s1dd1@ya.ru, пароль приложения от пользователя): заметка с VALARM дошла до сервера;
  «куда писать» на «Заметках» — по-прежнему local. Пароли со страницы — через `inbox.ini`.
- **Праздники** (решение 16, в том же 0.3): плагин Plasma `holidaysevents` по `Calendar` на
  показанный месяц (`Holidays.qml`); регионы — общий с часами файл
  `plasma_calendar_holiday_regions` (ничего не выбрано — регион локали, у нас ru_ru); смена
  через помощник Plasma доходит без перезапуска. Выходной — цветом выходных; «все, кроме
  именин», «все и именины» и мировые дни (11, свой список, по умолчанию выкл.) —
  `colorHoliday` #C8A35A; стикер называет их строками «* …». Что выходной и что именины —
  `HolidayKinds.js` из `calendar/holidays.py` (перезапускать после обновления KHolidays).
  Страница «Праздники»: выбранные списком с кнопкой «Убрать», ниже поиск и все 170 регионов
  одной строкой (название по ISO на языке интерфейса, язык плана серым).
- **Палитры** — пять виджетов (`stock`, `amber`, `warm-ash`, `tachikoma`, `tachikoma-rooftops`

- Переводы: календарь 167 msgid, монитор 282; `extract.py` идемпотентен, пропусков нет.

⚠️ `/usr/bin/{qml,qmllint,qmltestrunner}` — Qt 5; рабочие — `/usr/lib/qt6/bin/`. qmllint с

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (1). Данные — ksystemstats (2). Визуализатор свой (4). Датчики находятся
  сами (6). Переводы — ki18n (7). Сквозные клики — самим плазмоидом (8), окна погашены (9).
- Погода — прямые запросы из QML (10), источники за абстракцией, Яндекс нет (13). Плеер:
  маска по кнопкам (11), в спектре опцией и отдельным виджетом (12).
- Активные строки (14): маска — функция, откат — прямоугольник; программы — в своём scope.
- Заметки: один протокол CalDAV на троих; хелпер на Python в пакете; секреты не в командной
  строке (`inbox.ini`, каталог 700); своих заметок на день сколько угодно.
- Напоминания (15): VALARM в данных, расписание считает скрипт; в стикере поле времени и
  строка выбора (по слову пользователя), текстовый синтаксис остаётся; своя заметка без
  будильника молчит; ack/snooze локальны, ключ — с временем звонка; один лист за раз.
- Праздники (16): из плагина Plasma, регионы общие с часами (сказано на странице); выходной —
  по `public` в планах; мировые дни — свой список.
- Чужие ветки вливаются слиянием, локальные коммиты не переписываются.
- Никогда не `pkill -f`. Звук для проверок — только через null-sink.
