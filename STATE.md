## Задача следующей сессии — левая кнопка сквозь плазмоид

**Пользователь поставил:** найти всё-таки способ, чтобы **плазмоид** пропускал на рабочий
стол и **левую** кнопку мыши, — разведкой и подсмотрев в чужих проектах.

Что известно и проверено (`docs/GOTCHAS.md`, «Плазмоид отдаёт правую кнопку, но никогда
левую»; решение 5 в `docs/DECISIONS.md`):

- `enabled: false` у представления (наша настройка «Мышь») отдаёт **только правую** кнопку.
  Пользователь проверил плазмоид из магазина 2026-09-22: левая ловится, как и записано.
- Левую держит обёртка апплета (`ItemContainer` в оболочке рабочего стола) — ждёт долгого
  нажатия для режима правки. Четыре попытки мимо: `enabled: false`, `locked = true`
  (в Plasma 6 только читается), `immutability=2` у контейнера, и у контейнера, и у апплетов.
- Окно с `Qt.WindowTransparentForInput` пропускает обе кнопки — поэтому существуют
  оконные хосты. Цена: нет диалога настроек Plasma, правило KWin, свой автозапуск.

Направления для разведки (гипотезы, **ничего не проверено**):

1. **Чужие плазмоиды**, которые заявляют сквозные клики: KDE Store (Plasma 6 Extensions),
   GitHub (запросы вроде `plasmoid click through`, `WindowTransparentForInput plasma`,
   `desktop widget pass mouse events`), форумы KDE Discuss, баг-трекер KDE.
2. **Исходники оболочки рабочего стола** (plasma-desktop `containments/desktop`,
   libplasma `ContainmentItem`/`AppletQuickItem`, `ItemContainer`): где именно ловится
   левая, есть ли свойство или условие, которое это выключает.
3. **Плазмоид, рисующий в собственное окно** — `PlasmaCore.Dialog`/`Window` (или
   layer-shell через LayerShellQt) с `Qt.WindowTransparentForInput`, у самого апплета
   пустое представление. Тогда остаётся диалог настроек Plasma, а клики проходят, как у
   оконного хоста. Проверить: даёт ли plasmashell такому окну пустую область ввода под
   Wayland и можно ли поставить его под другие окна.
4. **Скрипт KWin / правило** — вряд ли: рабочий стол и апплеты — одно окно plasmashell.

Первый шаг — отдать разведку агенту (метод проекта), затем проверять исполнением на
одноразовом плазмоиде, как это делалось для ki18n (`plasmawindowed`).

Заодно решить: подпись «пропускать клики на рабочий стол» обещает больше, чем делает, —
предлагалось «пропускать правую кнопку…» и подсказка про оконный хост (десять языков,
версия 0.2 в магазине). Если найдётся способ для левой — подпись станет правдой.

## Где мы

**Два виджета, оба свои, у каждого два хоста.** ⚠️ **Сейчас на столе у каждого по два
экземпляра:** окна (как обычно) **и** оба плазмоида, которые пользователь поставил из
магазина и посадил на стол при проверке. `--status`: «added to the desktop (instances: 1)».
Лишние — убрать по его решению. Копия прежних настроек и пакетов (до проверки) —
`~/.local/share/plaintop-backup/2026-09-22/`; пакеты уже возвращены из репозитория.

- **Текстовый монитор** — `monitor/` (`package/`, `shared/`, `window/`, `generate.py`).
- **Визуализатор** — `spectrum/`; `cava` через службу-реле, реле — писатель настроек окон.
- **Датчики находятся сами** (решение 6); **сетевой интерфейс ранжируется** (шлюз →
  трафик → имя).
- **Десять языков** (решение 7, ki18n): язык и «Форматы» у Plasma; ru — ручной перевод,
  восемь — машинные. Вывод скриптов — английский.
- **Плазмоиды по умолчанию кликабельны**; «Мышь» пропускает правую кнопку.
- **Опубликовано и проверено.** GitHub: релиз
  [v0.1](https://github.com/highscrren-dotcom/plaintop/releases/tag/v0.1). KDE Store:
  монитор https://store.kde.org/p/2372814/, визуализатор https://store.kde.org/p/2372815/.
  В API магазина появились в 11:11 UTC (задержка несколько часов для всего магазина),
  MD5 файлов совпадают с нашими; пользователь нашёл их поиском в «Загрузить новые
  виджеты» и поставил — установка из магазина работает.
- **`--status` сверяет с репо всю раскладку**, включая `.mo` обоих хостов.
- **`conky/`** — погашена, живёт до замены.

⚠️ В `~/.config/plaintop/monitor.json` пользователя — `interface: enp4s0` (старое имя
карты); монитор обходит, редактор предупреждает. Не трогали.

## Потом

- Отзывы из магазина; машинные переводы — по замечаниям носителей.
- Обновление в магазине: `Version` в `metadata.json` → `--pack` → файл и версия товара.
- По нагрузке: пауза при блокировке экрана; кольцо под музыкой; двоичный вывод cava.
- Спектр: пик-холд, устройство в редакторе, пауза под полноэкранным окном.
- Температуры по пакетам CPU; R/W диска; секунды часов при 700 мс; генератор для conky;
  проверка на второй машине.

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (1). Данные — ksystemstats (2). Визуализатор свой (4).
- Сквозные клики — оконным хостом (5) — **до тех пор, пока разведка не найдёт способ для
  плазмоида**; это и есть задача следующей сессии.
- Датчики находятся сами (6). Переводы — ki18n, язык Plasma (7).
- Заголовок — дело пользователя. Плазмоиды по умолчанию кликабельны.
- Окна ищутся по таблице процессов, никогда не `pkill -f`. Цену меряем с дочерними.
