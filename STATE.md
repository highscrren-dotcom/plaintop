Обновлено: **2026-09-22**, после публикации (коммит `d2d2f6d`).

## Где мы

**Работают два виджета, оба свои, у каждого два хоста. На столе сейчас окна** (сквозь
них проходят обе кнопки мыши); плазмоиды установлены, но на стол не посажены.

- **Текстовый монитор** — `monitor/`: `package/` (хост-плазмоид), `shared/` (данные,
  рендерер, `SensorRegistry`), `window/` (хост-окно и редактор), `generate.py`. Весь набор
  блоков conky-реализации; набор и порядок — данные (`schema/widget.json`).
- **Визуализатор звука** — `spectrum/`: кольцо, дуга или линия; `cava` через службу-реле
  по локальному HTTP, реле же единственный писатель настроек окон обоих виджетов.
- **Датчики находятся сами** (решение 6). **Сетевой интерфейс ранжируется**: шлюз →
  пройденный трафик → имя, один раз на набор (ksystemstats отдаёт интерфейсы в порядке
  хэша, но только подключённые аппаратные — docker0/tun туда не попадают).
- **Десять языков** (решение 7, ki18n): язык и «Форматы» берутся у Plasma, переключателя в
  виджете нет. Исходные строки английские; ru — ручной перевод, uk, de, fr, es, pt_BR, pl,
  zh_CN, ja — машинные, помечены в заголовках каталогов. Каталоги — `po/`
  (`extract.py` обновляет, `build.py` собирает, `msgfmt --check` при каждой установке).
  Переведены и пункты меню/автозапуска окон (`Name[xx]` в `.desktop`).
- **Вывод скриптов в терминале — английский**, без перевода.
- **Заголовок по умолчанию пустой** — пишет пользователь; без текста виден только хост.
- **`services.sh`** отдаёт поля (`docker|2|5`), и молчит о том, чего на машине нет.
- **Опубликовано.** GitHub: описание, 14 тем, релиз
  [v0.1](https://github.com/highscrren-dotcom/plaintop/releases/tag/v0.1) с двумя `.plasmoid`
  (скачанные совпадают с собранными побайтно). KDE Store: монитор
  https://store.kde.org/p/2372814/ (Plasma 6 Monitoring), визуализатор
  https://store.kde.org/p/2372815/ (Plasma 6 Multimedia). В API магазина (откуда берёт
  «Загрузить новые виджеты») на момент записи ещё не появились — синхронизация.
  Сборка — `./install.sh --pack`, тексты и порядок загрузки — `docs/STORE.md`.
- **Плазмоиды по умолчанию кликабельны** (`clickThrough = false`): сквозные клики —
  «Общее/Поведение → Мышь»; настоящие сквозные клики — у оконных хостов.
- **`--status` сверяет с репо всю раскладку**, включая `.mo` обоих хостов.
- **`conky/`** — погашена (`./install.sh --conky-on` возвращает), живёт до замены.

⚠️ У пользователя в `~/.config/plaintop/monitor.json` сохранён `interface: enp4s0` — старое
имя сетевой карты. Монитор его обходит (показывает `enp5s0`), редактор пишет «enp4s0 нет
на машине»; очистить — «— найти самому —» в редакторе. Не трогали: настройка его.

   файл и поднять версию товара (`docs/STORE.md` → Uploading).

По нагрузке, если продолжать экономию:

- **пауза, пока экран заблокирован** — разведка: реле и D-Bus `org.freedesktop.ScreenSaver`;
- **кольцо под музыкой**: `Behavior` гонит отрисовку на 60 кадрах при данных на 30;
- **реле читает cava двоично** (`data_format=binary`) — выигрыш только под музыкой;
- **ollama при загруженной модели** всё ещё через CLI — не на чем проверить.

Из накопившегося:

- **спектр: пик-холд**, выбор устройства в редакторе, пауза под полноэкранным окном,
  диапазон частот;
- **температуры по пакетам CPU** — сейчас максимум по ядрам узла;
- **чтение и запись диска** в строке «/»;
- **секунды часов при интервале 700 мс** тикают неровно;
- **генератор для conky**;
- **проверка на второй машине**.

## Что уже решено, не пересматривать без причины

- Движок — плазмоид (решение 1). Данные — ksystemstats (решение 2).
- Визуализатор свой (решение 4). Рисуем процессором, видеокарту не нагружаем.
- **Сквозные клики — оконным хостом** (решение 5).
- **Датчики находятся сами** (решение 6).
- **Переводы — штатный ki18n** (решение 7): язык Plasma, без переключателя в виджете.
  Исходные строки английские; вывод скриптов — английский без перевода.
- Заголовок — дело пользователя, по умолчанию пустой.
- Окна ищутся по таблице процессов, никогда не `pkill -f`.
- Цену меряем вместе с дочерними процессами (`cutime + cstime`).

## Открытые вопросы

- **Судьба conky-реализации** после замены: удалять или оставить запасной.
