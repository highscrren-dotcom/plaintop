# spectrum — визуализатор звука

[English](README.md) · Русский

Рисует спектр того, что играет, в том же плоском стиле, что и текстовый монитор: один
цвет, прямые концы, без градиентов и свечения. Кольцо, дуга или линия.

Почему свой, а не готовый — `../docs/DECISIONS.ru.md`, решения 3 и 4. Некоторое время у
него был второй хост, окно со сквозными кликами, появившееся из-за левой кнопки
(решение 5 — плазмоид на рабочем столе её не отдавал, а обычное окно отдаёт). Раз плазмоид
пропускает обе кнопки сам (решение 8, `../docs/GOTCHAS.ru.md`), этот хост погашен
(решение 9): хост один, плазмоид; код лежит в `window/`, но не ставится.

## Как устроено

```
cava ──► relay.py ──► плазмоид ──► Ring.qml
 FFT   локальный HTTP
```

| Часть | Что делает |
|---|---|
| `shared/Spectrum.qml` | опрашивает реле, решает, играет ли что-нибудь, отдаёт полосы сигналом |
| `shared/Ring.qml` | рисует их: штрих — прямоугольник в шарнире нулевого размера, поэтому кольцо, дуга и линия отличаются только местом шарнира |
| `relay.py` | держит `cava`, отдаёт её полосы по `http://127.0.0.1:8788` и **владеет файлом настроек** |
| `window/window.qml` | погашенный оконный хост: окно с `Qt.WindowTransparentForInput` (решение 9) |
| `window/settings.qml` | редактор этого хоста, с живым просмотром — погашен вместе с ним |
| `package/` | хост-плазмоид, со штатным диалогом настроек Plasma |

Плазмоид берёт два общих файла — `install.sh` копирует их в пакет. Правленная копия — верный
способ тихо разъехаться с `shared/`.

⚠️ QML не умеет писать файлы, поэтому редактор погашенного хоста не трогал `ring.json`: он
читал `GET /config` и отправлял правки в `POST /config`, а файл писало реле. Один хозяин
лучше двух писателей — то же правило проект уже выучил на `~/.config/conky`. Плазмоид же
держит настройки в штатном хранилище Plasma.

## Установка

```bash
./install.sh --spectrum            # плазмоид и служба реле
./install.sh --windows-off         # погасить оконный хост прежней установки (решение 9)
./install.sh --status              # плазмоид, порт реле, погашенное окно
```

`--spectrum-window` и `--spectrum-settings` ещё есть, но относятся к погашенному хосту, и
пользоваться ими не нужно.

Нужны `cava` и `msgfmt` (gettext, для переводов).
Свои настройки реле — устройство, число полос, частота, сглаживание, диапазон частот, как
скоро cava засыпает в тишине — лежат в окружении службы; переопределяются в
`~/.config/plainspectrum/relay.env`.
После трёх секунд тишины cava перестаёт считать и смотрит на вход раз в секунду
(`PLAINSPECTRUM_SLEEP`, `0` выключает): 3,9 % ядра в тишине становятся 0,35 %, а кольцо
появляется до секунды позже, когда звук возвращается.

`--spectrum` сажает плазмоид на стол; воздерживается он лишь пока настроено ещё не
погашенное окно — сначала `--windows-off`. Кольцо двигается как любой виджет, в режиме
правки рабочего стола.

## Настройки

Правый клик → «Настроить»; диалог группирует их: форма, вид, поведение, тишина.

| Настройка | Что делает |
|---|---|
| Раскладка | кольцо или линия; кольцо с охватом меньше 360° — это дуга |
| Штрихи, толщина, зазор | плотность и вес штрихов |
| Радиус, охват, начальный угол | геометрия кольца |
| Длина в тишине / на максимуме | насколько далеко тянется штрих |
| Рост | от основания: у кольца наружу, внутрь или в обе стороны; у линии вверх, вниз или в обе стороны |
| Зеркально, обратный порядок | сложить спектр сам на себя или развернуть |
| Элемент | сплошная полоска или лестница из блоков |
| Размер и зазор блока | шаг лестницы; число блоков выводится из длины |
| Цвет, второй цвет, прозрачность | плоский цвет либо переход ко второму по спектру |
| Направляющая окружность | тонкое неподвижное кольцо под штрихами |
| Кадров данных в секунду | как часто хост опрашивает реле |
| Сглаживание, мс | анимация Qt, заполняющая промежутки между кадрами данных |
| Растворять в тишине | без звука кольцо исчезает, а на звуке вырастает из невидимого кольца |
| Порог, задержка, плавность, опрос в тишине | что считать тишиной, сколько ждать, как медленно растворять, как редко опрашивать |

⚠️ **Блоки** рисуют штрихи × блоки элементов, и цена растёт по обоим. **Сглаживание**
намеренно сделано анимацией Qt, а не циклом на JavaScript: та же доводка на JS обошлась
втрое дороже.

## Отладка

```bash
curl -s http://127.0.0.1:8788/state    # кадры, перезапуски cava, источник, возраст последнего кадра
curl -s "http://127.0.0.1:8788/bands?bars=16"
journalctl --user -u plainspectrum-relay -f
```

⚠️ `/state` появился из-за настоящего отказа: cava выходит при смене звукового
устройства, а первая версия реле давала потоку чтения просто закончиться и дальше отдавала
нули. Виджет при этом выглядел как в тишине. Теперь реле надзирает за cava и
перезапускает её, а `/state` делает «одни нули» читаемыми, а не поводом для догадок.

## Что предстоит

- **Пик-холд** — точка, которая держит максимум и медленно оседает.
- **Выбор источника в редакторе** — устройство пока задаётся в `relay.env`.
- **Пауза под полноэкранным окном** — тишина кольцо уже скрывает, но игра со своим звуком
  держит его бодрым.
- **Диапазон частот в редакторе** — он уходит в cava, значит нужен перезапуск реле.
