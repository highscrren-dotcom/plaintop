# spectrum — визуализатор звука

[English](README.md) · Русский

Виджет Plasma 6, который рисует спектр того, что играет, в том же плоском стиле, что и
текстовый монитор: один цвет, прямые концы, без градиентов и свечения.

Почему свой, а не готовый — `../docs/DECISIONS.ru.md`, решения 3 и 4. Коротко: принятый
в этой нише виджет растеризует картинку процессором через QML `Canvas`, и на нужном
размере это стоит около 31 пункта видеокарты и половины ядра.

## Как устроено

```
cava  ──►  relay.py  ──►  виджет
 FFT     локальный HTTP   элементы сцены
```

- **`cava`** считает спектр. Она упакована, отлажена и дешёвая: 2–3 % одного ядра.
- **`relay.py`** отдаёт полосы cava по `http://127.0.0.1:8788` строкой чисел через
  запятую. Реле нужно потому, что cava льёт поток и не завершается, а движок
  `executable` в Plasma отдаёт вывод только после завершения команды, и читать файл из
  QML нельзя. Локальный HTTP разрешён — см. `../docs/GOTCHAS.ru.md`.
  Работает пользовательской службой systemd: переживает перезапуск оболочки и умирает
  вместе с сессией, а не остаётся сиротой.
- **Виджет** просит столько полос, сколько рисует (`?bars=N`, прореживает реле), и
  двигает готовые прямоугольники. Ничего не растеризуется покадрово, поэтому видеокарта
  держится на половине процента.

## Установка

```bash
./install.sh --spectrum    # виджет + служба реле + посадить на рабочий стол
./install.sh --status      # раздел «Спектр» читает порт, а не только состояние systemd
```

Нужна `cava` (`sudo pacman -S cava`). Настройки самого реле — устройство, число полос,
частота, сглаживание, диапазон частот — лежат в окружении службы; переопределяются в
`~/.config/plainspectrum/relay.env`.

## Форма и вид

Один рендерер даёт несколько форм, потому что штрих — это прямоугольник в шарнире
нулевого размера: меняется только то, где шарнир стоит и насколько повёрнут.

| Настройка | Что делает |
|---|---|
| Раскладка | кольцо или линия; кольцо с охватом меньше 360° — это дуга |
| Штрихи, толщина, зазор | плотность и вес штрихов |
| Радиус, охват, начальный угол | геометрия кольца |
| Длина в тишине / на максимуме | насколько далеко тянется штрих |
| Рост | наружу, внутрь или в обе стороны от основания |
| Зеркально, обратный порядок | сложить спектр сам на себя или развернуть |
| Элемент | сплошная полоска или столбик блоков |
| Цвет, второй цвет, прозрачность | плоский цвет либо переход ко второму по спектру |
| Направляющая окружность | тонкое неподвижное кольцо под штрихами |
| Кадров данных в секунду | как часто виджет опрашивает реле |
| Сглаживание, мс | анимация Qt, которая заполняет промежутки между кадрами данных |
| Мышь | снимает приём ввода у представления — для настоящего пропуска кликов этого мало, см. `../docs/GOTCHAS.ru.md` |
| Растворять в тишине | без звука кольцо исчезает, а на звуке вырастает из невидимого кольца |
| Порог, задержка, плавность, опрос в тишине | что считать тишиной, сколько ждать, как медленно растворять и как редко опрашивать, пока скрыто |

⚠️ Две настройки стоит понимать до того, как их увеличивать. **Блоки** рисуют
штрихи × блоки элементов, и цена растёт по обоим. **Сглаживание** намеренно сделано
анимацией Qt, а не циклом на JavaScript: та же доводка на JS обошлась втрое дороже.

## Что предстоит

- **Пик-холд** — точка, которая держит максимум и медленно оседает.
- **Выбор источника в диалоге** — сейчас устройство задаётся в `relay.env`.
- **Пауза под полноэкранным окном** — тишина кольцо уже скрывает и опрос роняет до пары запросов в секунду, но игра со своим звуком всё равно держит его бодрым.
- **Диапазон частот в диалоге** — он уходит в cava, значит нужен перезапуск реле.
- **Рендерер на шейдере** — ещё дешевле, но переносит работу на видеокарту, чего здесь
  сознательно не хотели.
