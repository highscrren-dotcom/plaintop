# plaintop на Windows 11

[English](README.md) · Русский · протокол: [PROTOCOL.md](PROTOCOL.md) (по-английски)

Те же пять виджетов — текстовый монитор, визуализатор звука, плеер, погода и календарь —
на рабочем столе Windows 11, нарисованные теми же файлами QML, что и виджеты KDE Plasma.
Ничего из Plasma не нужно: каждый виджет — окно без рамки и фона, которое запускает
собственный `qml.exe` из Qt, а одна маленькая служба на Python кормит все пять показаниями,
настройками и заметками календаря. Как это выбрано и чего стоит — решение 17 в
[../docs/DECISIONS.ru.md](../docs/DECISIONS.ru.md).

⚠️ **Состояние.** Порт написан в Linux-контейнере, без машины с Windows, и проверен там на
голом Qt (6.8, 6.10 и 6.11) против заменителя службы и Python-стендами самой службы; job CI на
`windows-latest` — первое место, где он встретился с Windows, и он зелёный: стенды службы, хосты,
загруженные `qml.exe` против настоящей службы, и zip — всё offscreen, без стола. То, что покажет
только стол —
захват звука, медиасессия, датчики из LibreHardwareMonitor, вид флагов окна, трей,
уведомление, — на столе ещё не видел никто. Отчёты приветствуются.

## Что нужно

- **Windows 11** (10, вероятно, тоже; не пробовали).
- **Python 3.12** с python.org или из Store, и `pip install numpy psutil holidays tzdata
  tzlocal`. Необязательно, каждый пакет даёт одну вещь: `winsdk` — плеер (System Media
  Transport Controls); `soundcard` или `pyaudiowpatch` — захват звука для визуализатора
  (WASAPI loopback вывода по умолчанию); `pycaw` — строка звука у монитора.
- **Qt 6.8 и новее** — нужен только `qml.exe` с модулями QML. Онлайн-установщик Qt
  (скажем, `C:\Qt\6.10.3\msvc2022_64`) или `pip install aqtinstall` и
  `aqt install-qt windows desktop 6.10.3 win64_msvc2022_64`. Хосты проходят свой стенд на
  6.8, 6.10 и 6.11; CI берёт 6.10.
- **Шрифт**: *JetBrainsMono Nerd Font Mono* — `JetBrainsMono.zip` с
  [nerdfonts.com](https://www.nerdfonts.com/font-downloads), распаковать и каждый `.ttf`
  установить для пользователя (правая кнопка → *Установить*). Без него виджеты берут первый
  моноширинный шрифт, какой есть в Windows (Cascadia Mono, Consolas, Lucida Console, Courier
  New — в этом порядке), так что колонки остаются колонками, но значки Nerd и символьные
  значки погоды теряют форму. (На Windows «monospace» не имя семейства: первый стол работал на
  Segoe UI, и проценты монитора гуляли.)
- **LibreHardwareMonitor** (необязательно) ради температур и вентиляторов: запустить,
  *Options → Remote Web Server → Run* (порт 8085). Без него этих показаний нет, и строки,
  которым они нужны, молчат — как на Linux без `lm_sensors`. Блоку GPU он не нужен: загрузка
  и память — из счётчиков производительности, которые читает диспетчер задач, карты и их
  память — из DXGI, температура и мощность карты NVIDIA — из `nvidia-smi`; у Intel и AMD
  температуры без LHM нет.
- **Звук**: спектр слушает тот выход, на который идёт музыка — сначала выход по умолчанию,
  потом остальные по кругу, пока текущий молчит (Windows отдаёт звук программы туда, куда
  указала программа или настройка «вывод для приложения», а не всегда на выход по умолчанию;
  на первом столе по умолчанию была USB-гарнитура, а музыка шла на колонки). `PLAINTOP_CAPTURE`,
  часть имени выхода, закрепляет выбор; `/state` называет выход в `source`, а в `scan` — что
  слышал простаивающий захват на каждом. Если кольцо тёмное при музыке, открыть
  `http://127.0.0.1:8788/devices`, пока она играет: каждый выход с пиком, который на нём слышно.
- **Клик — это клик**: окна не забирают активацию (`noActivate` в ini, включено), так что
  нажатие на кнопку плеера срабатывает из любого окна, где вы работали, и то окно остаётся
  в фокусе. Листы календаря — отдельные окна, они фокус берут.
- **Погода** ходит к источникам через службу (`/fetch`): она читает прокси из настроек системы
  и доверяет системному хранилищу сертификатов — собственные запросы голого окна в
  корпоративной сети остались «offline». Прокси из PAC-скрипта не читается; тогда службе
  нужен `HTTPS_PROXY`.

## Запуск из репозитория

```powershell
git clone https://github.com/highscrren-dotcom/plaintop.git
cd plaintop
python win\build.py --qt C:\Qt\6.10.3\msvc2022_64   # копирует общий QML, конвертирует каталоги
python win\plaintop.py                              # служба, виджеты, значок в трее
```

`build.py` собирает `win\host\<виджет>\` из общих исходников, как `install.sh` собирает
пакеты плазмоидов, и пишет переводы в `win\host\i18n\`. `plaintop.py` запускает службу на
`127.0.0.1:8788`, затем каждый виджет, у которого включена настройка `shown`, и значок в
трее. `qml.exe` ищется в `PLAINTOP_QML`, затем в `PATH`, затем под `C:\Qt`;
`pythonw win\plaintop.py` запускает без окна консоли.

**Значок в трее** — вход, пока виджеты пропускают клики: какие виджеты показаны, настройки
каждого, выход. **Настройки** открываются в своём окне — те же страницы, поля и слова, что
в диалоге Plasma, — и пишутся в `%APPDATA%\plaintop\<виджет>.ini`, который можно править и
руками; работающий виджет подхватывает их за секунду. **Мышь** (страница «Общее» или меню
самого виджета) делает виджет прозрачным для ввода: каждый клик попадает на стол, как у
виджетов Plasma до активных строк. Когда выключено — левая кнопка тянет виджет, правая
открывает его меню: настройки, переключатель мыши, *за значками стола*, закрыть. Место
запоминается.

**Где лежит окно.** Инструментальное окно внизу стопки — позиция «Bottom» у Rainmeter; Qt
сам держит его там. Два следствия: *Показать рабочий стол* (Win+D) прячет виджеты, пока стол
не уберут, а значки стола рисуются поверх них там, где пересекаются. **За значками стола**
(экспериментально, выключено) сажает окно под `WorkerW` обоев, как движки обоев; зависит от
сборки Windows (24H2 перенесла этот слой внутрь Progman) и гибнет с перезапуском Explorer.
**`softwareRender`** (в ini, выключено) запускает виджет на программном бэкенде Qt Quick:
такое окно рисуется с попиксельной альфой, и Windows по документации пропускает мышь сквозь
его прозрачные пиксели — кандидат на клики, которые доходят до текста и больше ни до чего.
Ни одно из трёх на столе не видели: попробуйте и расскажите
([../docs/research/windows-widgets.ru.md](../docs/research/windows-widgets.ru.md) — источники
и чеклист).

**Уведомление напоминания** — тост Windows под идентификатором PowerShell (настольное
приложение без ярлыка в «Пуске» поднять тост не может), поэтому над текстом стоит «Windows
PowerShell». **Defender** покажет «Windows protected your PC» для неподписанного zip:
*Подробнее → Выполнить в любом случае*. **LibreHardwareMonitor** для датчиков нужны права
администратора, в автозагрузку его не положить — запускать из Планировщика с наивысшими
правами.

**Zip.** Каждый зелёный прогон CI хранит `plaintop-win.zip` артефактом `plaintop-win`
(*Actions → checks → прогон → Artifacts*): `plaintop.exe` с замороженной службой, `host/` и `qt/` с
`qml.exe` и модулями — распаковать куда угодно, запустить `plaintop.exe`; шрифта и необязательных
пакетов внутри нет. Собирает `win/package.py`; job CI запускает только что упакованный
`plaintop.exe` (`PLAINTOP_NO_HOSTS=1`, одна служба) и спрашивает у него `/monitor`, `/bands`,
`/settings`, `/holidays`, `/notes`, прежде чем сохранить артефакт. Замороженная служба находит
свои файлы рядом с exe (`win/service/paths.py`); `PLAINTOP_ROOT` задаёт другой корень руками,
`PLAINTOP_PORT` — другой порт. Первый запуск на столе (05.10.2026) умер окном
`FileNotFoundError: …\spectrum\relay.py` — от этого шаг и страхует; exe с `--noconsole`
показывает необработанное исключение таким окном и ничем больше.

**Автозапуск:** ярлык в папке автозагрузки (`Win+R`, `shell:startup`) на
`pythonw.exe C:\путь\к\plaintop\win\plaintop.py`.

## Чем отличается от Plasma

| | Plasma | Windows |
|---|---|---|
| Хост | плазмоид | `qml.exe`, по окну на виджет |
| Сквозные клики | везде, кроме активных строк, кнопок плеера, ячеек календаря (решения 11, 14) | всё окно: включено — мышь не берёт ничто; выключено — всё |
| Активные строки | включены по умолчанию | выключены по умолчанию: пункты — линуксовые команды |
| Праздники | 170 регионов KHolidays, выбор по названию | пакет `holidays`, ISO-коды (`DE`, `DE-BY`, `RU`) на странице «Праздники» |
| Напоминание рядом с листом | `notify-send`, `pw-play` | уведомление, `winsound` |
| Настройки | диалог Plasma, конфиг оболочки | своё окно, `%APPDATA%\plaintop\*.ini` |
| Датчики | ksystemstats | psutil, JSON LibreHardwareMonitor, `winget`, журнал событий |
| Источник визуализатора | cava | WASAPI loopback и numpy |

## Стенды

```powershell
python tests\win_service.py        # датчики, эмуляция команд, сервер
python tests\win_bands.py          # анализатор спектра на синтетических сигналах
python tests\win_media.py          # отображение плеера, notes.py в службе, праздники, пояса
python tests\win_hosts.py --qt C:\Qt\6.10.3\msvc2022_64   # пять хостов через шимы против настоящей службы
```

Последний собирает хосты, запускает службу на свободном порту, гоняет
`tests\win_hosts.qml` в `qmltestrunner` offscreen и останавливает службу. Все четыре идут в
CI на `windows-latest` (`.github/workflows/check.yml`).

## Раскладка

- `win/host/` — пять хостов (`monitor.qml`, …), `tray.qml`, `settings.qml`, а в `imports/`
  — подмены на чистом QML для модулей Plasma, которые импортируют общие файлы, и модуль
  `plaintop` (клиент службы, функции i18n, базовое окно).
- `win/service/` — служба на Python: `server.py` (маршрутизатор), `monitor_win.py`,
  `exec_win.py`, `bands.py`, `player_win.py`, `notes_bridge.py`, `holidays_win.py`,
  `timezones.py`, `settings_store.py`, `ui.py`, `notify_win.py`.
- `win/build.py`, `win/plaintop.py` — сборка и запуск.
